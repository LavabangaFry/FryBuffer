# FryBuffer

Ряд круглых эмодзи-кнопок у края экрана. В покое у края видны только
цветные точки; подвели к ним мышь — точки волной раскрываются в
кружки, без какой-либо подложки: на экране только сами кнопки.
Клик по кружку кладёт его текст в буфер обмена. Текст может быть
шаблоном: с датой, логином, счётчиком или вопросом, который задаётся
при клике.

Те же кнопки открываются сеткой прямо у курсора по **Win+Alt+V** — с
номерами 1–9 и поиском, после выбора фокус возвращается в окно, где
вы печатали, и остаётся нажать Ctrl+V.

## Раньше называлась clipbuttons

С версии 2026.10.13 программа называется **FryBuffer**, файл —
`FryBuffer.exe`. Переезд проходит сам при первом запуске:

- работающая панель под старым именем закрывается и уступает место;
- `config.json` рядом с exe тот же — кнопки на месте; если настройки жили
  в `%APPDATA%\clipbuttons`, они копируются в `%APPDATA%\FryBuffer`;
- автозапуск «clipbuttons» переписывается на FryBuffer;
- старый кеш эмодзи в `%LOCALAPPDATA%\clipbuttons` удаляется.

Старый `clipbuttons.exe` после этого можно удалить.
## Запуск и перенос

Вся программа — **один файл `FryBuffer.exe`**, около 4 МБ: скрипты,
образец конфига и эмодзи вшиты внутрь. Положить его куда угодно и
запустить. Рядом появится только `config.json` с вашими кнопками.

exe собирается из этой папки одной командой, интернет не нужен:

```
powershell -NoProfile -File tools\build-exe.ps1
```

В репозитории его нет, так что после `git pull` собрать заново. Сборка
показывает по шагам, что происходит: версию, проверку скриптов на
синтаксис, значок, упаковку эмодзи, компиляцию и проверку готового exe.
Если панель запущена из этого же exe, сборка закроет её на время замены
и запустит снова уже новую.

Как это устроено. Скрипты выполняются из памяти PowerShell'ом в том же
процессе — отдельного `powershell.exe` в диспетчере задач нет, на диск
ничего исполняемого не распаковывается, политика выполнения скриптов не
мешает. Картинки эмодзи один раз распаковываются в
`%LOCALAPPDATA%\FryBuffer\emoji-<версия>`; при обновлении exe с
другим набором старая копия удаляется сама.

Нужен штатный Windows PowerShell 5.1 и .NET Framework 4 — они есть в
любой Windows 10/11. Если PowerShell зажат политикой AppLocker или WDAC
(режим ограниченного языка), панель не запустится ни из exe, ни из папки.

Без exe тоже можно: `FryBuffer.vbs` запускает панель прямо из папки
с исходниками. Так удобно при разработке.

При первом запуске `config.json` создаётся из образца — семь кнопок-зверей
в цветах радуги, поэтому в покое точки у края складываются в радугу. У
🦄 Единорога-сервера четыре вложенных зверька — так видно, как работает
веер. Всё это можно править или удалить.

Панель работает в одном экземпляре. Новый запуск **сменяет** уже
работающую: старая закрывается, новая встаёт на её место. Поэтому после
обновления достаточно запустить новый exe — закрывать прежний не нужно.

### Версия

Версия — дата и номер коммита, из которого собран exe, например
`2026.10.13 · fd34ccc`. Её видно:

- в меню трея, первой строкой, и в подсказке значка;
- в заголовке окна настроек;
- в свойствах файла: правый клик → Свойства → Подробно;
- в каждой строке `FryBuffer-error.log`.

После запуска новой версии внизу экрана всплывает «FryBuffer обновлён ·
…». `+правки` в версии значит, что exe собран из папки с
незакоммиченными изменениями. При запуске из папки (`FryBuffer.vbs`)
версия берётся у git и помечается «из папки».
### Где лежат настройки

Обычно `config.json` и `FryBuffer-error.log` — рядом с программой.
Если в папку программы писать нельзя (её положил администратор, запись
режет «Контролируемый доступ к папкам» Защитника), они живут в
`%APPDATA%\FryBuffer`, и при первом переезде туда копируется прежний
`config.json`. Это решается при каждом запуске пробной записью; если
запись отказала уже во время работы, панель переезжает сама и показывает
об этом короткое уведомление. «Открыть config.json» в трее всегда
открывает тот файл, который используется сейчас.

## Автозапуск

Трей → «Запускать вместе с Windows» или переключатель на вкладке «Вид и
поведение» в настройках. Включается сразу, без «Сохранить». Записывается
в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` — прав
администратора не нужно.

Если папку перенесли или копий две, переключатель в настройках покажет,
какая копия сейчас стоит в автозапуске; включение в нужной копии
перепишет запись на неё.
## Как пользоваться

| Действие | Что происходит |
|---|---|
| Подвести мышь к точкам у края | Панель выезжает, кружок под мышью увеличивается |
| Клик по кружку | Текст в буфере, кружок вспыхивает зелёным |
| Правый клик по кружку | Пилюля: ✏️ изменить, 😀 эмодзи, 🎨 цвет, 📋 копия, 🗑️ удалить |
| Перетащить кружок | Поменять порядок, остальные расступаются |
| Ctrl + перетащить кружок | Перенести панель к любому краю любого монитора |
| Ctrl + правый клик по кружку | Новая кнопка, настройки, закрепить, скрыть |
| Задержать мышь на кружке с точками | Веер вложенных кнопок вокруг него |
| **Win+Alt+V** | Сетка кнопок у курсора: 1–9, стрелки, Enter, пробел — вложенные, поиск набором |

Удаление в пилюле — со второго нажатия: промах по соседнему значку не
должен стоить кнопки с длинным шаблоном.

## Вложенные кнопки — веер

Чтобы не городить ряд из десятка похожих кружков, кнопки группируются.
Например, «Основной сервер» по клику копирует свой адрес, а если
задержать на нём мышь, вокруг него дугой раскрываются резервный, тестовый
и остальные — такие же кнопки: клик копирует, есть подсказка и правый клик.

- Кружок с вложенными помечен точками по внешней кромке — по одной на
  вложенную, не больше пяти.
- Задержка раскрытия — 0,4 с, меняется ползунком в настройках
  («Через сколько раскрывать вложенные веером»).
- Веер держится, пока мышь на нём или на родителе; уходит, если мышь
  ушла или задержалась на другом кружке панели.
- До семи кружков на первой дуге, остальные — на следующей. У угла экрана
  дуга сама поворачивается в сторону свободного места.
- Кнопка без своего текста работает как папка: клик сразу раскрывает
  вложенные.
- Уровень вложенности один: у вложенной своих вложенных нет.

Заводятся вложенные в настройках, в списке они стоят с отступом под
родителем:

| Кнопка под списком | Что делает |
|---|---|
| + Вложенная | Новая вложенная у выбранной кнопки (или у родителя выбранной вложенной) |
| В группу | Кнопка панели становится вложенной у кнопки выше |
| На панель | Вложенная становится обычной кнопкой панели, сразу за родителем |
| ↑ ↓ | Порядок внутри своего ряда: панели или веера |

Ещё быстрее — правый клик по кружку → 📂 «Добавить вложенную».

В сетке по Win+Alt+V вложенные показываются отдельным рядом, если
задержать мышь на родителе или нажать пробел; поиск находит их сразу.
## Шаблоны

В тексте кнопки можно использовать подстановки. В окне настроек они
вставляются кнопками под полем текста, а ниже сразу видно, что получится.

| Подстановка | Что подставится |
|---|---|
| `{date}` | Сегодняшняя дата: `07.10.2026`. Свой формат: `{date:yyyy-MM-dd}` |
| `{time}` | Время: `14:05` |
| `{now}` | Дата и время; формат как у даты: `{now:dd MMMM, HH:mm}` |
| `{clipboard}` | То, что лежит в буфере в момент клика |
| `{user}` | Имя пользователя Windows |
| `{computer}` | Имя компьютера |
| `{ip}` | Адрес компьютера в локальной сети (адаптер со шлюзом) |
| `{?Номер заявки}` | При клике появится поле с этой подписью |
| `{n}` | Счётчик кнопки, растёт на 1 при каждом копировании; `{n:0000}` — с нулями |
| `{guid}` | Новый GUID |
| `{rand:12}` | Случайный код заданной длины без похожих символов `0 O 1 l I` |
| `{{` и `}}` | Буквальные фигурные скобки |

Неизвестное в фигурных скобках остаётся как есть, поэтому JSON в тексте
кнопки не ломается.

Пример — ответ на заявку:

```
Добрый день!
Заявка {?Номер заявки} принята в работу {date} в {time}.
С уважением, {user}
```

## Меню в трее

Правый клик по значку:

| Пункт | Что делает |
|---|---|
| Скрыть / показать панель | То же, что левый клик по значку. Скрытая панель доступна по Win+Alt+V |
| Закрепить открытой / прятать к краю | Кружки видны всё время или только при наведении |
| Сетка у курсора | То же, что Win+Alt+V |
| Новая кнопка… | Открывает настройки с новой кнопкой |
| **Настройки…** | **Кнопки, вид, поведение, хоткей** |
| Открыть config.json | Тот же конфиг текстом в блокноте |
| Папка панели | Открывает папку в проводнике |
| Запускать вместе с Windows | Автозапуск при входе: ✅ включён, ⬜ выключен |
| Перезапустить | Запускает панель заново |
| Выход | Завершает процесс |

Windows 11 прячет новые значки под шеврон `^` в трее. Чтобы значок был на
виду: Параметры → Персонализация → Панель задач → Другие значки в области
уведомлений → включить `powershell`.

## Настройки

Правый клик по значку в трее → «Настройки…». Руками JSON править не
нужно.

- Вкладка **«Кнопки»**: слева список, справа название, текст, цвет
  обводки и эмодзи. Эмодзи выбираются как на телефоне — вкладки
  категорий и поиск по-русски и по-английски («кот», «ключ», «server»).
- Вкладка **«Вид и поведение»**: тема (как в Windows, тёмная, светлая),
  акцент, размер кружков, край экрана, задержка перед тем, как
  спрятаться, хоткей.
- Всё на вкладке «Вид» применяется к панели **сразу**, пока двигаете
  ползунок. На диск — по «Сохранить» (или Ctrl+S).
- «Сохранить» окно не закрывает. «Закрыть» с несохранёнными изменениями
  срабатывает со второго нажатия и возвращает всё как было.

## config.json

| Ключ | Значения | По умолчанию |
|---|---|---|
| `theme` | `auto`, `dark`, `light` | `auto` — как в Windows |
| `accent` | `blue`, `green`, `purple`, `orange`, `pink` | `blue` |
| `size` | `S`, `M`, `L` — диаметр 20, 24, 30 | `M` |
| `edge` | `bottom`, `top`, `left`, `right` | `bottom` |
| `offset` | 0…1 — положение вдоль края | `0.5` |
| `screen` | Имя монитора, `""` — основной | `""` |
| `magnify` | Увеличивать кружок под мышью | `true` |
| `hideDelay` | 150…3000 мс до того, как спрятаться | `450` |
| `fanDelay` | 150…1500 мс задержки мыши до раскрытия вложенных | `400` |
| `mode` | `auto`, `pinned`, `hidden` | `auto` |
| `hotkey` | `Win+Alt+V`, `Ctrl+Shift+F5`…; `""` — выключен | `Win+Alt+V` |
| `items` | Кнопки: `name`, `text`, `icon`, `color` (`#RRGGBB` или `rainbow`), `ring` (`solid`, `dotted`, `dashed`, `double`), `counter`, `children` — вложенные того же вида | — |

Ошибка в значении не роняет запуск — берётся значение по умолчанию.
Конфиг, который не читается как JSON, откладывается рядом как
`config.broken-<время>.json`, и панель стартует с чистыми настройками —
тексты кнопок можно достать из отложенного файла. Прежняя версия
конфига после каждого сохранения лежит в `config.json.bak`.

## Симптом → что смотреть

| Симптом | Причина и что делать |
|---|---|
| Нет ни точек, ни значка в трее | Смотреть `FryBuffer-error.log` рядом с программой или в `%APPDATA%\FryBuffer` |
| Настройки «не там», где программа | Папка программы закрыта для записи — они в `%APPDATA%\FryBuffer`, см. «Где лежат настройки» |
| FryBuffer.exe удалён антивирусом | Запускать `FryBuffer.vbs` из папки с исходниками |
| exe: «нет ресурса … пересоберите» | exe собран не полностью — `tools\build-exe.ps1` ещё раз |
| Точек нет, значок серый | Панель скрыта: левый клик по значку |
| Win+Alt+V не работает | Настройки → «Вид и поведение»: под полем хоткея написано, занят ли он. Выбрать другой |
| Вместо цветного эмодзи буква | Символа нет в наборе `emoji/img` — выбрать эмодзи из списка в настройках |
| После вставки `{?…}` фокус не там | Окно, где печатали, закрылось или сменилось, пока был открыт вопрос |
| Панель уехала за край после смены монитора | Ctrl + перетащить кружок к нужному краю или «Положение вдоль края» в настройках |
| В логе `Access to the path is denied` при сохранении `config.json` | Нет права записи в папку панели. Сетевой диск сам по себе не мешает: если файловый сервер не даёт подменить файл, конфиг записывается поверх, а прежний кладётся в `.bak` |

## Разработка

```
powershell -NoProfile -File tests\run-tests.ps1
```

Проверки ядра: шаблоны, хоткей, чтение и запись конфига. Без внешних
модулей — Pester 5 со штатным PowerShell 5.1 не дружит.

```
powershell -NoProfile -STA -File tools\snapshots.ps1 -Theme dark -Out snapshots
```

Рисует все окна (меню, сетку, настройки, запрос) в PNG, не показывая их
на экране: так проверяется вёрстка, не отнимая фокус у человека за
машиной.

```
powershell -NoProfile -File tools\build-emoji.ps1
```

Пересобирает набор эмодзи и каталог `emoji/catalog.json`. Нужен
интернет; результат кладётся в репозиторий.

```
powershell -NoProfile -File tools\build-exe.ps1
```

Собирает `FryBuffer.exe` из `launcher\FryBuffer.cs`, вшивая в него скрипты, `config.example.json` и `emoji`, и рисует значок
`launcher\FryBuffer.ico`. Компилятор `csc` входит в .NET Framework 4 —
он есть в любой Windows, интернет не нужен. `FryBuffer.exe --restart`
сначала ждёт, пока прежний экземпляр завершится, — так работает
«Перезапустить» в трее.

Файлы `.ps1` хранятся в UTF-8 **с BOM**: без него PowerShell 5.1 читает
их в кодировке ANSI и ломается на кириллице.

| Файл | Что внутри |
|---|---|
| `launcher/FryBuffer.cs` | Исходник `FryBuffer.exe`: выполняет вшитые скрипты в своём процессе |
| `FryBuffer.ps1` | Запуск: лог ошибок, один экземпляр, конфиг, таймеры, трей, хоткей |
| `dock.ps1` | Панель: кружки, анимация, перетаскивание, меню, сетка, трей |
| `settings.ps1` | Окно настроек |
| `ui.ps1` | Палитра, стили, всплывающие окна, эмодзи, выбор эмодзи |
| `core.ps1` | Без окон: шаблоны, конфиг, разбор хоткея |
| `native.ps1` | Вызовы Windows: «не забирать фокус», хоткей, возврат фокуса |
